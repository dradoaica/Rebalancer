# Protocols

On-demand parts of the canonical agent contract, kept out of `.agents/AGENTS.md` to save context. They have the **same
precedence** as `.agents/AGENTS.md` and must not contradict it; surface any conflict to the human.

When to read each file is defined in `.agents/AGENTS.md` → **How to use this document**.

## Adding a protocol

- Only for content that a minority of tasks need and that has a clear trigger.
- Start it with the precedence banner used by the existing files.
- Add its trigger to the table in `.agents/AGENTS.md`.
