# Rebalancer 4.0.0 – release notes

Packages: `Rebalancer.Core`, `Rebalancer.SqlServer`, `Rebalancer.Redis`, `Rebalancer.ZooKeeper`,
`Rebalancer.Extensions.DependencyInjection` (all 4.0.0).

Change record: [CR-0006](../change-records/CR-0006-release-4-0-0.md). **Breaking for Redis provisioning only.** No API
change. SQL Server and ZooKeeper behave as in 3.2.0.

## Redis: each group in its own keys

[ADR-0020](../adrs/0020-per-group-redis-leases-and-resources.md), [US-0020](../user-stories/US-0020-redis-per-group-keys-in-4-0.md).

A group's settings and lease now live in `RBR:Lease:{group}` and its resources in `RBR:Resources:{group}`. The first
4.0 node of a group moves them out of the shared keys automatically. Upgrade all nodes of a group at once, update
provisioning scripts, and read [migrating-to-4.0.md](migrating-to-4.0.md) first.

- A Redis ACL user can now be confined to one group with no access to any shared key.
- A heartbeat reads only its own group's resources.
- The 3.2 warning about this change is gone.

## Rollback

Back to 3.2.0 needs the group's entries moved back to the shared keys, or re-provisioned there; see the migration
guide.
