# Rebalancer 5.2.0 – release notes

Packages: `Rebalancer.Core`, `Rebalancer.LeaseCoordination`, `Rebalancer.SqlServer`, `Rebalancer.PostgreSql`,
`Rebalancer.Redis`, `Rebalancer.ZooKeeper`, `Rebalancer.Extensions.DependencyInjection`,
`Rebalancer.Extensions.Diagnostics.HealthChecks` (all 5.2.0).

Change record: [CR-0015](../change-records/CR-0015-release-5-2-0.md). No configuration or data format change; nodes can
be upgraded one at a time.

## Improvement: a Redis group settles more reliably over a slow link

[PRB-0009](../problem-records/PRB-0009-redis-group-does-not-converge-over-a-lossy-link.md),
[ADR-0036](../adrs/0036-redis-coordinator-writes-client-records-one-at-a-time.md). Affects Redis and Valkey.

The coordinator wrote all nodes' records in one optimistic transaction, which failed whenever any node's keep-alive
landed during it. Over a link whose round trip is a sizeable fraction of the heartbeat, it failed ten times in a row,
the coordinator restarted, and the group could stay unassigned for minutes. Now each node's record is written on its
own, which makes these conflicts much rarer (in the test that showed them, failures fell from 3 in 6 runs to 2 in
26). They are not gone: the remaining fix is planned for 6.0. Safety is unchanged: every write still requires the
lease, and a grant that fails part-way cannot make two nodes process the same resource (checked with the TLA+ model).
Until 6.0, keep a Redis group's heartbeat well above the Redis round trip.

## Deprecated for 6.0

[ADR-0034](../adrs/0034-public-api-of-the-lease-based-backends-in-6-0.md). These public types are not part of the
supported API and become internal in 6.0; using them gives warning **RBR0034**:

- `Rebalancer.LeaseCoordination.Roles.ClientEvent`, `CoordinatorToken`, `EventType`
- `Rebalancer.LeaseCoordination.Store.AssignmentStatus`
- `Rebalancer.Redis.ResourceGroup`, `Rebalancer.Redis.Resources.Resource`, `Rebalancer.Redis.Utils.Constants`
- `Rebalancer.SqlServer.Connections.ConnectionHelper`

None of them appears in a public signature; the providers and the service interfaces are unchanged.

## New: `ClientNotFoundException` is public

A custom `IClientService` throws `Rebalancer.LeaseCoordination.Clients.ClientNotFoundException` from
`KeepAliveAsync` when the client's record is gone (e.g. expired); the client then registers again, as with the
built-in services.

## Builds

Packages are published only after the unit tests and a dependency scan pass; the scan stops a release on a High or
Critical vulnerability. Pull requests run the unit and integration tests
([ADR-0035](../adrs/0035-tests-and-dependency-scan-in-ci.md)).
