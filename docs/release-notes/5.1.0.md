# Rebalancer 5.1.0 – release notes

Packages: `Rebalancer.Core`, `Rebalancer.LeaseCoordination`, `Rebalancer.SqlServer`, `Rebalancer.PostgreSql`,
`Rebalancer.Redis`, `Rebalancer.ZooKeeper`, `Rebalancer.Extensions.DependencyInjection`,
`Rebalancer.Extensions.Diagnostics.HealthChecks` (all 5.1.0).

Change record: [CR-0014](../change-records/CR-0014-release-5-1-0.md). No public API, configuration or data format
change. Fixes found by the review after 5.0.0; nodes can be upgraded one at a time, and 5.0.0 and 5.1.0 nodes share a
group.

## Fixes

- **SQL Server, PostgreSQL: a node's keep-alive carries its fencing token.** The check that a delayed start still
  belongs to the same grant (4.3.2, [PRB-0007](../problem-records/PRB-0007-assignment-delay-delays-keep-alives.md))
  compares resources and token; the token was always 0 on these backends, so only the resources were compared. Redis
  was not affected.
- **SQL Server: a node that waited for the group row sees the lease's real age.** The lease time was taken when the
  statement started, before the wait, so a node could be denied a lease that had expired while it waited and had to try
  again a heartbeat later. Now the time is read once the row is locked, as on PostgreSQL. Renewals were already
  stamped correctly.
- **PostgreSQL: a coordinator that stalls while assigning resources no longer blocks the others.** The server ends its
  transaction after half the lease expiry, as for the lease operations
  ([TM-0004](../threat-models/TM-0004-postgresql-coordination.md) D2).
- **SQL Server, PostgreSQL: `RecreateClientAsync` works when the client's record still exists.** It failed with a
  primary-key violation; now it replaces the record with a new registration, as on Redis.
- **All lease-based backends: `GetAssignedResources(CancellationToken)` returns after an abort or stop** instead of
  waiting until the token is cancelled.
- **All lease-based backends: a coordinator that stops releases its lease** even if it stopped before its first tick as
  coordinator; before, the release named token 0 and did nothing, and the next node waited for the lease to expire.
- Two providers in one process no longer share their start lock.

## Documentation

- SQL Server: a resource's group and name together must fit in 900 bytes
  ([PRB-0008](../problem-records/PRB-0008-resource-key-can-exceed-sql-server-index-limit.md)).
- [SECURITY.md](../../SECURITY.md): only 5.1.x is supported. 4.3.x gets no further fixes: .NET 8 and .NET 9 reach end
  of support on 10 November 2026; move such hosts to .NET 10 together with Rebalancer.
