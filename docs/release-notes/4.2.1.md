# Rebalancer 4.2.1 – release notes (security)

Packages: `Rebalancer.Core`, `Rebalancer.SqlServer`, `Rebalancer.Redis`, `Rebalancer.ZooKeeper`,
`Rebalancer.Extensions.DependencyInjection`, `Rebalancer.Extensions.Diagnostics.HealthChecks` (all 4.2.1).

Change record: [CR-0009](../change-records/CR-0009-release-4-2-1.md). No API, behavior or data change.

## Security: CVE-2026-84008 in System.Security.Cryptography.Pkcs (SQL Server backend)

[ADR-0025](../adrs/0025-pin-patched-system-security-cryptography-pkcs.md), [PRB-0004](../problem-records/PRB-0004-vulnerable-transitive-pkcs-in-sql-server-packages.md),
advisory [GHSA-846f-f764-76mx](https://github.com/advisories/GHSA-846f-f764-76mx) (High, CVSS 7.5: quadratic CPU
exhaustion from attacker-controlled X.509 certificate data).

`Rebalancer.SqlServer` and `Rebalancer.Extensions.DependencyInjection` up to 4.2.0 brought
`System.Security.Cryptography.Pkcs` 8.0.1 (or 9.0.18 on .NET 9/10 hosts) through `Microsoft.Data.SqlClient` 7.1.1. Both
are affected. 4.2.1 references the patched 10.0.13 directly, which NuGet then uses on every host.

**Upgrade** if you use the SQL Server backend. Redis and ZooKeeper users are not affected. If you cannot upgrade yet,
add a direct reference to `System.Security.Cryptography.Pkcs` 10.0.13 (or 8.0.2 / 9.0.21 matching your framework's
line) to your application.
